Help

Most problems here are one of about six things. Start with the status badge at the top of the page — if the realm is down, nothing below will help.

Connecting

The server appears in the list, but character select hangs forever

The realm is down. This is what "down" looks like from your side: the list still populates, because that comes from a different part of the server than the one that went away.

Check the badge at the top of this page. If it says the realm is online and you still cannot get in, that badge is wrong — say so and it will get fixed.

I forgot my password

There is no reset, because there are no email addresses attached to anything. Ask and your account can be looked at directly.

Do I need to type in a server address?

No. The launcher writes it for you every time it starts, and updates it if the realm ever moves. If someone gave you an IP address to type in, ignore it — it is probably out of date.

Installing

Extraction fails: "cannot open the file as archive"

An old build of the launcher, which shipped without the ability to read the archive format the game comes in. Download the launcher again from the install page and delete the old copy — nothing else needs redoing.

Windows says the publisher is unknown, or my antivirus quarantined it

Expected, and not a sign of anything wrong. The launcher is not code-signed, because a certificate costs several hundred dollars a year for a server with six players on it. Unsigned programs that download and unpack other programs trip most heuristics.

Click More info then Run anyway. If your antivirus removed the file, restore it and add an exclusion.

The download bar has not moved in ten minutes

Almost certainly still working. The game comes down in 53 separate parts and the bar only advances as each one finishes, so it sits still for long stretches. Give it an hour before you assume anything is wrong.

I pressed PLAY and it said "Ready to play" instead of starting

Working as intended. The first press installs, the second press launches. It is set up this way so a download that finishes at three in the morning does not throw you into a login screen unattended.

In game

My keybindings reset every time I log out

The client only writes bindings to disk when you press Accept in Options → Controls. Changes made without it apply to the session and are then thrown away.

Set your keys, press Accept, quit the game, and they will stick.

My window layout went back to default

Usually the result of the realm being renamed, since the client files those layouts under the realm's name and will not find them under the new one. The old layout is still on disk rather than lost. Ask before rebuilding your interface from scratch.

Will my character be wiped?

Possibly, while the realm is still being built. If it happens you will get warning first, and it will be announced rather than discovered. Do not get too attached to anything just yet.

Still stuck

None of this covers my problem

Say what you were doing, what you expected, and what happened instead. A screenshot of the error beats a description of it. If the launcher failed, the text in its window is the useful part.
